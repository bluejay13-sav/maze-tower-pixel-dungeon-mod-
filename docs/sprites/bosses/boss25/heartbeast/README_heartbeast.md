# 25층 최종보스 — 심장을 진 짐승 (b7_heartbeast)

모든 칸은 32×27. 배경 투명. 시트마다 가로 = 프레임, 세로 = 심장 박동 상태.

## 심장 박동 행(4행 공통)
| 행 | 상태 |
|---|---|
| 0 | 쉼(기본) |
| 1 | 두 (가장 크게, 심장·혈관 밝게) |
| 2 | 두와 근 사이(살짝 부푼 상태) |
| 3 | 근 (두보다 조금 작게, 밝게) |

박동은 **실제 시간 기준 48 bpm**(1.25초에 한 세트), 이동·공격 속도와 무관하게 따로 돈다.
한 세트를 16칸으로 나눈 리듬: `두(1) → 사이(1) → 근(1) → 쉼(13)` — 한 칸 = 78.125ms.
→ 매 프레임 `행 = 리듬표[(경과시간 % 1.25s) / 78.125ms]`, `열 = 다리 시계`.

## 방향·회전
- 이동 방향 → 그림: 좌우·대각선 = 옆모습, 아래 = 정면, 위 = 뒷모습.
- 방향을 바꿀 때 제자리에서 멈추지 않고 이동하며 곡선으로 회전. 회전 중에는 현재 진행 각도로 그림을 고른다
  (0°=오른쪽, 시계방향): 30↓ 옆 / 30–55 튼옆(아래) / 55–80 정면3/4 / 80–100 정면 / 100–150 그 반전 / 150–210 옆(반전) /
  210–235 튼옆(위, 반전) / 235–260 뒷3/4(반전) / 260–280 뒷모습 / 280–305 뒷3/4 / 305–330 튼옆(위).
- 회전 프레임은 달리기보다 빠르게(약 55ms vs 95ms). 오른쪽으로 틀 때와 왼쪽으로 틀 때 거치는 그림이 다르다.
- 이동 속도가 올라가면 다리 시계만 빨라진다. 심장 시계는 그대로.

## 이펙트(런타임, 시트에 그리지 않음)
- 은은한 글리치: 실루엣 좌우 1칸 붉은/푸른 잔상(평소 알파≈28, 글리치 순간≈70), 가끔 1~2줄 가로 띠 ±1칸 밀림.
  평소 확률 12%, 심장이 두·근 뛰는 칸에서는 35%.
