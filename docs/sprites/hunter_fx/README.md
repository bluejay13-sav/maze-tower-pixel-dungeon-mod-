## 피드백 반영 (2026-11-21 밤)
- 톤: 정화(13)·상태이상 면역 보호막(14)은 톤 다운 전 원래 그림. 흘리기 반격·열기·역경·충전 터뜨리기 13종·금화·정령 매 날기/소환/사라짐은 잘 보이게 밝기를 올림. 나머지는 톤 다운 그대로.
- 충전 터뜨리기 수호(26)는 보라색, 이식(27)은 더 분홍빛으로 바꿈.
- 삭제: 맨손 타격(07), 던지기 부딪힘(15), 흐르는 충전 불꽃(16) — 코드에서 재생하는 곳을 지운다.

## 피드백 반영 2 (2026-11-21 밤)
- 삭제: 혈점 표시(09), 상태이상 면역 보호막(14). 정화(13)는 보호막 그림을 빼고 반짝임만(4프레임).
- 흘리기 반격(10) 다시 그림: 잘 보이게 은빛 막기 → 사선 반격.
- 충전 터뜨리기: 화염·냉기·전격·붕괴·굴절광 밝게, 대지는 더 밝게, 부식은 원작 부식 색(회색~주황), 수호는 선명한 보라, 재성장은 선명한 초록, 타락은 밝기 대신 대비·채도를 올림. 마탄을 뺀 12종은 4프레임으로 줄이고 **한 프레임 0.05초**로 빠르게.
- 금화 튀김(30) 다시 그림: 밝은 금화 3개가 반짝이며 튀어 오름(옆으로 선 동전과 번갈아).
- 그대로: 급소 번쩍임(08).
