- `bloom_core.png`·`fullbloom_core.png` (16×16): 개화의 핵·만개의 핵 새 아이템 그림. 결실의 핵은 `fx4_12`.
- (결정) 개화의 핵·만개의 핵을 쓸 때 꽃이 피는 연출은 **삭제**(특성 창에 가려 보이지 않음).
- (결정) 강타의 화면 흔들림은 1픽셀, 아주 짧게(0.1초 안).
- (결정) 넘치는 힘은 돌지 않는다. 주인공 둘레에 은은하게 숨 쉬는 기운만.
- (결정) 냉기는 눈송이만, 발밑 서리는 깔지 않는다.
- (결정) 빙결·해빙은 빠르게(한 프레임 0.06초).
- `fx4_10` 반응 글자: 지금 뜨는 반응 이름(증기·폭발·해빙·빙결) 글자를 이 색(위→아래 그러데이션, 밝은 윗줄, 어두운 테두리)으로 바꾼다.
- `fx4_13` 반지 스킬 버튼: 고리지기 반지 스킬 버튼 아이콘(`ring_buttons_preview.png`는 확대 견본).
- 2차 특성 시트 `docs/sprites/talent2/fx2_sheet.png`도 같은 배치(150×192) 그대로 새 그림으로 바꿨다(바람 줄기 은빛+벚꽃잎, 마나 충격파 남빛, 표식 터짐 작게 3프레임, 강철 파편, 진홍 표적, 마나 돔, 마나 파편, 머리 위 표식 꽃잎 모양). 잔상 칸(0,163)은 비웠다(거리 벌리기는 삭제됨).
