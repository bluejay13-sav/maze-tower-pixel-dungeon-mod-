## 피드백 반영 (2026-11-21 밤)
- 톤: 대부분 잘 보이게 밝기를 다시 올림. 처형·영웅의 도약·가시갑옷·인내·표식 터짐은 더 밝게, 으깨기·마나 반환은 살짝만. 집중·흐름 준비, 조준 과녁, 마력 파편은 톤 다운 그대로.
- **놓는 자리**(32×32 칸의 가운데 = 대상 칸의 가운데):
  - 찌르기(fx3_01)·급소 찌르기(05)·기습(06): 그림이 주인공 쪽(시트 왼쪽)에서 나오고 몬스터를 지나자마자 사라지게 다시 그렸다. **적 칸 가운데**에 놓고 주인공→적 방향으로 돌린다.
  - 받아치기(23): 0~1프레임 막는 칼(대각선)은 주인공 몸 쪽, 2~3프레임 칼날 궤적은 적 가운데. **적 칸**에 놓는다.
  - 분노 폭발(25)·잔향 각성(fx4_09)·연속 베기(fx4_01): 칼날이 **적 칸 가운데**에 생긴다(주인공 칸이 아님).
  - 강타(fx4_02): 크기를 줄이고 가운데로 옮김.
- 반월베기(03): 푸른 작은 달 입자 추가. 빙결(11): 밑의 원 없앰, 3프레임.
- 영웅의 도약(16)·가시갑옷(20): 더 잘 보이게 굵게.
- 마나 장막·흘리기(fx4_08): 커졌다 작아지는 폭을 줄임.
- 젖음(fx3_14): 머리를 가리지 않게 몸 아래쪽으로, 덜 눈에 띄게(그림 자체에 반투명이 들어 있으니 코드에서 더 흐리게 하지 않는다).
- 삭제: 조준 사격 적중(fx3_07), 메치기(fx3_22), 2차 방어 무시 파편(fx2_sheet (0,102)) — 코드에서 재생하는 곳을 지운다.
- 2차 시트(talent2/fx2_sheet.png): 표식 터짐 더 잘 보이게, 마나 장막 그림 다시(더 얇고 은은하게), **머리 위 표식 4개** = 3개 세모 + 오른쪽 아래 표식의 오른쪽 위에 하나 (16×9 칸, 표식 왼쪽 위 좌표 (3,0)(0,5)(6,5)(10,2)).
