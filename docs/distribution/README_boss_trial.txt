Maze Tower - Boss Trial (Windows)

Maze Tower is an unofficial fan mod of Shattered Pixel Dungeon (by Evan Debenham / Shattered Pixel).
It is not affiliated with or endorsed by Shattered Pixel. Please don't report Maze Tower bugs to them.

How to play: unzip the whole folder, then run "Maze Tower.exe". No Java install needed.
Press Play on the title screen and pick one of three boss fights.
If Windows shows "Windows protected your PC", click "More info" -> "Run anyway".

미궁의 마탑 - 보스전 체험판 (Windows)

미궁의 마탑은 Shattered Pixel Dungeon(녹픽던)을 바탕으로 만든 비공식 팬 모드입니다. 원작 개발자와 관계없습니다.

시작 화면에서 플레이를 누르고 보스전 세 가지 중 하나를 고르세요.
