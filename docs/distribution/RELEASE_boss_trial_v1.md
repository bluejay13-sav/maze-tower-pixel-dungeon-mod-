**Maze Tower – Boss Trial v1 (Windows)**

Maze Tower is an **unofficial fan mod** of [Shattered Pixel Dungeon](https://shatteredpixel.com/shatteredpd/) by Evan Debenham. It is not affiliated with or endorsed by Shattered Pixel — please don't report Maze Tower bugs to them.

This test build lets you try three boss fights right away, as the Warrior:
- Floor 5: Rotting Sap Mass (start on floor 4, level 6)
- Floor 20: Wraith King (start on floor 19, level 19)
- Floor 20: Mage-City Empress (start on floor 19, level 19)

**How to play**
1. Download `MazeTower-BossTrial-win64.zip` below.
2. Unzip the whole folder (don't run it from inside the zip).
3. Run `Maze Tower.exe`. No Java install needed.
4. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

Windows 10/11, 64-bit only. License: GPL v3.0. Source code: this repository (`boss-trial` branch).

**미궁의 마탑 – 보스전 체험판 v1 (Windows)**

미궁의 마탑은 Shattered Pixel Dungeon(녹픽던)을 바탕으로 만든 **비공식 팬 모드**입니다. 원작 개발자와 관계없으니 버그는 원작 개발자에게 알리지 말아 주세요.

전사로 보스전 세 가지를 바로 해 볼 수 있는 시험 버전입니다.
- 5층 썩은 수액 덩어리 (4층·레벨 6에서 시작)
- 20층 망령 왕 (19층·레벨 19에서 시작)
- 20층 마도시의 여제 (19층·레벨 19에서 시작)

**실행 방법**
1. 아래 `MazeTower-BossTrial-win64.zip`을 받습니다.
2. 압축을 모두 풉니다 (zip 안에서 바로 실행하지 마세요).
3. `Maze Tower.exe`를 실행합니다. 자바 설치는 필요 없습니다.
4. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

Windows 10/11 64비트 전용. 라이선스: GPL v3.0. 소스 코드: 이 저장소(`boss-trial` 브랜치).
