# 사냥꾼 명세 (활 7종 · 3차 · 4차) — 2026-11-21

기준 원본: Claude 문서 "사냥꾼 활 7종", "사냥꾼 3차·4차". 이 파일은 그 내용을 구현용으로 옮긴 것이다.
본편(main)과 체험판(`boss-trial` 브랜치) **둘 다**에 적용한다.

## 0. 공통 규칙
- 2차·3차·4차가 열리는 시점은 모든 직업이 같다(전사와 동일: 5층 개화의 핵, 10층 만개의 핵, 20층 결실의 핵).
- 활 거리 규칙(지금 구현 유지): 1칸 = 근접 평타(피해 낮음, 1칸 밀쳐냄, 화살 안 씀) / 2칸 = 원거리, 명중 -30% / 3칸 이상 = 원거리, 패널티 없음 / 최대 사거리 = 보이는 곳까지(화살길이 열린 적).
- 활 스킬 마나 30. 스킬은 화살 1발(여러 발 쏘는 스킬은 쏜 수만큼)을 쓴다.
- **강화형 스킬**(석궁 '장전', 정량궁 '집중')은 1턴을 쓰고 다음 원거리 평타를 강화한다. 장전·집중 행동 자체는 공격 스킬이 아니므로 2차 스킬 특성을 받지 않는다. **강화된 평타는 스킬 판정**이라 스킬에 영향을 주는 특성(2차 스킬 특성, 추적자 사냥감 지정 등)이 적용된다.
- 활 힘 요구치는 검 7종과 같다.

## 2. 3차(만개) — 둘 중 하나
3차 특성 4개, 0→4레벨, 포인트 Lv13~20 8개 + 물약 3 = 최대 11 (전사와 같음).

### ① 고리지기 — 반지 빌드(맨손)
- 전직하면 모든 반지의 고유 능력(패시브·스킬)이 열린다. 원작 반지 효과에 **더해지는** 것이지 대체하지 않는다.
- **반지 고유 능력은 무기를 들지 않았을 때만** 쓸 수 있다.
- 반지는 원작처럼 두 개까지. 패시브는 어느 칸에 끼든 적용된다. **스킬이 있는 반지 두 개를 끼면 두 스킬 모두 쓸 수 있다**(반지 스킬 버튼 두 개). (2026-11-21 바뀜: 예전 '첫 칸 반지 스킬만' 규칙과 착용 순서 안내는 없앤다.)
- 무기를 들고 있으면 반지 패시브와 스킬을 **둘 다** 쓸 수 없다.
- 반지 고유 능력 설명은 고리지기 사냥꾼에게만 보인다(다른 직업·전직 전에는 원작 설명만).
