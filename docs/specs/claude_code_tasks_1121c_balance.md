## 4. 20층 보스 — 구조 변경
- 두 보스가 같이 쓰는 체력 `B20_HP`·`B20_HP_STRONG`을 보스마다 나눈다: `WK_HP`·`WK_HP_STRONG`, `EM_HP`·`EM_HP_STRONG`.
- 망령 왕 기본 공격 배율 `WK_BASIC_MULTI`(근접·영혼 화살 공통 0.4)를 둘로 나눈다: `WK_MELEE_MULTI`(바로 옆, 방어 적용), `WK_ARROW_MULTI`(떨어진 주인공에게 영혼 화살, 방어 무시).
- 기습 일격이 기본 공격 배율을 따라가고 있으면 따로 `WK_AMBUSH_MULTI`를 만든다(`WK_AMBUSH_DMG` ×1.3은 그대로 곱한다).
