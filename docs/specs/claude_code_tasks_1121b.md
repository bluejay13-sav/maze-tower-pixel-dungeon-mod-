## 3. 놓는 자리 바로잡기
- 찌르기·급소 찌르기·급소 찌르기 기습: 적 칸 가운데에 놓고 주인공→적 방향으로 돌린다(그림이 주인공 쪽에서 나와 적을 지나자마자 사라진다).
