## 1. 공통 연출 규칙 (새로 추가)

- **화면 흔들림은 항상 1px, 1프레임.**
- **보스·의태 영웅이 기술을 시전하는 순간마다 1px 흔들림**(평타 제외). 예외: **3페이즈에는 흔들림이 없다.** 3페이즈에서 흔들리는 건 튕기는 돌진이 **벽에 부딪히는 순간 1번뿐**이다.
- **영웅 피격 이펙트**: 의태 영웅·사슴의 공격에 맞으면 영웅이 하얗게 번쩍(1프레임) + 맞은 방향으로 1px 움찔. 원작 피격 표시와 함께 쓴다.
- 빛은 왼쪽 위에서 오는 것으로 명암을 넣고, 이펙트는 은은하게.

## 2. 1페이즈 — 살점과 오염

- 시작 시 살점 **2개**, 이후 **6턴마다 1개**씩 생성, **최대 4개**. 영웅·사슴 발밑과 둘에게서 3칸 이내에는 생기지 않는다.
- 사슴은 살점 하나를 **3턴** 동안 먹고 최대 체력 **5%** 회복.
- **오염**: 살점에 아래 물약을 던지거나 마법봉을 쏘면 살점이 오염된다. 사슴이 오염 살점을 먹으면 **회복하지 않고** 해당 상태이상에 걸린다. 사슴은 원래 상태이상 면역이지만 이 경우만 예외.
- 상태이상과 지속시간은 **원작 코드의 효과·지속시간을 그대로** 가져온다(새 수치를 만들지 않는다).

| 오염시키는 것 | 살점 색 | 사슴이 먹으면 |
|---|---|---|
| 유독 가스 물약 | 초록 | 독 |
| 마비 가스 물약 | 누런 노랑 | 마비 |
| 서리 물약 / 서리 마법봉 / 혹한 | 차가운 푸른색 + 윗면 서리 | 냉기 |
| 부식 마법봉 | 녹슨 주황(원작 부식 구름 색) | 부식 |
| 타락 마법봉 | 검보라 + 검은 혈관 | 원작 타락 마법봉이 보스에게 거는 디버프 |

- 한 살점에 여러 번 오염시키면 **마지막 것만** 남는다.
- **오염되는 순간 연출**: 날아오는 것 없이, 살점 **바깥 테두리부터 안쪽으로** 한 겹씩 오염 색으로 번진다(경계 1px은 원래 색과 섞인 중간색). 약 0.6초. 참고: `preview/flesh_contaminate_moment.gif`
- 오염 살점은 **움직이는 효과 없음**(정지 그림). 시트: `sprites/b7_flesh_contaminated.png`(16px × 6칸: 일반·독·마비·냉기·부식·타락).

## 3. 2페이즈 — 의태 영웅 연출 변경

- **마법사 혈탄**: 끝이 뾰족한 핏빛 탄환이 **직선으로** 날아간다(곡선·소용돌이 없음).
- **마법사 혈관 가시밭**: 가시는 끝으로 갈수록 가늘어지는 명암 있는 가시.
- **전사 혈관 도약**: 점선 경로 없음. 착지 순간 3×3이 번쩍이고 중심에서 균열이 갈라지며 파편·핏방울이 튄다.
- **도적 이중 발톱**: 1타는 앞손 칼(위→아래), 2타는 **뒷손 칼**(아래→위로 엇갈림).
- **도적 독바르기**: 칼날은 움직이지 않고, 보랏빛 독이 칼날 결을 따라 스며든다. 가끔 한 방울 떨어짐.
- **사냥꾼 화살**: 실제 화살처럼 촉·대·깃(깃은 대와 평행, 바깥으로 꺾이지 않음). 화살통 없음.
- **대처 연출(새로 추가)** — 참고: `preview/fx25_all_stills.png`(위에서부터 순서대로), `preview/25F_5~7_*.gif`
  1. 마법사 가시밭 **시전 끊김**: 3×3 경고 칸이 조각나 흩어짐 → 지팡이 구슬이 터지고 피가 흘러내림 → 마법사 1px 움찔.
  2. 사냥꾼 관통 혈시 **조준 끊김**: 조준선이 토막 나 떨어지며 사라짐 → 사냥꾼 움찔.
  3. 도적 **은신 해제**(굴절광에 닿거나, 영웅을 때렸을 때): 그림자 막이 사방으로 찢겨 흩어짐 → 하얗게 번쩍 → 윤곽이 잠깐 빛남 → 1px 움찔.
  4. 혈관 덫 **태우기**: 불꽃이 핥고 덫이 시들어 재로 흩어짐.
  5. 혈관 덫에 **물건 던지기**: 촉수가 빈손으로 허공을 움켜쥐고 시듦.
  6. 혈관 덫 **드러남**(탐색·마법 지도·심안): 탐색 고리가 지나가면 덫이 서서히 나타나고 한 번 반짝.
- **의태 영웅 처치 → 사슴 복귀**: 무기가 먼저 사라지지 않는다. 시체가 **머리부터 발끝까지** 차례로 살점이 되어 무너지고, 그 자리에서 사슴이 **위에서 아래로** 다시 만들어진다. 참고: `preview/25F_8_의태_처치_복귀.gif`

## 4. 3페이즈 — 광폭화 변경

### 광폭화 표현
- 몸 주변의 붉은 기운 **삭제**(눈이 아픔).
- 대신 **사슴 몸 자체에 강한 글리치**: 진홍·보라 색수차 잔상이 좌우로 1~2px 갈라짐, 가로 띠가 2~3px씩 찢겨 밀림(한 번에 1~3줄), 가끔 밀린 띠 하나가 하얗게 번쩍. **심장이 뛰는 순간에 더 자주** 일어난다.
- 심장 박동이 몸에서 보이게(박동마다 심장이 하얗게 번쩍 + 작은 고리).

### 튕기는 돌진
- **첫 돌진은 영웅을 정확히 노리지 않는다**: 영웅 방향에서 **20°~35°** 무작위로(왼쪽/오른쪽 무작위) 비껴서 직선으로 달린다. 어느 벽(상하좌우)에 부딪힐지는 결과에 따른다.
- **벽에 부딪히면**: 몸이 납작하게 눌림(1프레임, **이때만 1px 흔들림**) → 튕겨 나옴 → 곧바로 새 방향으로 달림(벽을 따라 미끄러지지 않음).
- **튕김 방향**: 부딪힌 벽에서 **영웅 쪽**으로. 단 튕기는 방향과 **벽면 사이의 각도는 최소 25°, 최대 65°**. 영웅 방향이 이 범위를 벗어나면 가까운 끝값(25° 또는 65°)으로 고정되어 빗나갈 수 있다.
- 튕김은 **한 번**. 튕긴 뒤 다음 벽에 닿으면 멈추고(기절 없음) 옆모습으로 돌아온다.
- 경로는 칸 단위 직선(브레젠험 등)으로 계산한다. 방향은 8방향으로 끊지 않는다.
- **경고**: 돌진 전 1턴. 첫 돌진 경로는 벽까지 **전부** 표시. 튕긴 뒤 경로는 **최대 5칸**만, **벽에 가까운 칸일수록 진하고 멀수록 옅게**(진하기 100% → 78% → 58% → 40% → 25%). 경고 칸은 진행 중 지나간 칸부터 꺼진다.
- 영웅 적중: 피해·넉백은 오전 지시 값 그대로, 영웅 하얗게 번쩍 + 진행 방향으로 밀려남. 적중하면 사슴은 그 자리에서 멈춘다.
- 돌진 그림: 거의 가로(세로 성분이 작음)면 옆모습 달리기, 아래로 기울면 앞모습 대각선, 위로 기울면 뒷모습 대각선(왼쪽이면 좌우 반전).
- 참고: `preview/bounce_angles.gif`(17×11 방, 5가지 경우), `preview/25F_9_phase3_광폭화.gif`

### 심장 박동 파동
- 사슴이 **앞발로 바닥을 쿵 구르면** 핏빛 고리가 **한 턴에 한 칸씩** 퍼진다. 퍼지는 동안 화면 가장자리가 박동에 맞춰 어둡게 조였다 풀린다(비네트). 흔들림 없음.

### 살점 비
- 떨어질 칸에 1턴 전 **살점 덩어리 모양의 그림자**로 경고(원형 표시 아님).
- 살점은 작은 덩어리. 떨어지면 터지며 핏자국 얼룩만 남는다. **더미·장애물 없음.** 사슴이 살점에 끼는 일 없음.

## 5. 보스 체력바 페이즈 표시 (20층·25층 보스)

- 체력바에 **페이즈가 바뀌는 지점마다 금색 세로 눈금**을 긋는다. 눈금은 체력바 위아래로 1px씩 삐져나오고, 맨 위 1px만 밝게. 그림자 픽셀은 넣지 않는다.
- 이미 지난 눈금은 **회색으로 어둡게** 바뀐다.

| 보스 | 눈금 위치 |
|---|---|
| 20층 망령 왕 | 70%, 25% |
| 20층 마도시의 여제 | 85%, 30% |
| 25층 사슴 1페이즈 | 70% |
| 25층 사슴 2페이즈 | **10% 하나만** (체력이 100%로 다시 차면서 눈금도 바뀜. 의태 처치로 깎이는 25% 지점에는 눈금 없음) |
| 25층 사슴 3페이즈 | 체력바 대신 남은 턴(20 → 0) 표시. 그림은 나중에 주므로 지금은 숫자로 |

- 참고: `preview/boss_hp_phase_marks.png`(시안. 실제 원작 체력바 그림에 맞춰 위치만 따른다).
