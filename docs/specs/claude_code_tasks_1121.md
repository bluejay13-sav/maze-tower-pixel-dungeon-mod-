## 2. 20층 보스 연출 수정
견본 움짤: `docs/sprites/boss_fx/b20_wraith_all.gif`, `b20_empress_all.gif`, `wk_phase2_darkness.gif`. (두 움짤 위쪽의 설명 글자는 견본 설명일 뿐, 게임에 넣지 않는다.)

### 2-1. 망령 왕 1→2단계 "어둠이 찾아옴" (결정, 새 연출)
체력 70%에서 어둠이 될 때, 지금처럼 바로 깜깜해지지 않고 짧은 연출을 넣는다(약 3초, 연출 중에는 주인공이 행동하지 않음).
1. 화면 가장자리부터 점점 어두워지고, 밝은 원이 왕 쪽으로 좁혀져 **왕이 마지막으로** 남는다(약 2초, 가장자리는 부드럽게).
2. 완전히 깜깜해진다(약 0.7초).
3. 깜깜한 가운데 왕의 **푸른 눈**(기습 때의 푸른 눈과 같은 색 계열)이 **한 번 선명하게** 빛났다가 사라진다. 기습 눈처럼 25%로 비치지 않고 또렷하게. 밝기 단계 0.09·0.09·0.14·0.26·0.14·0.16초, 가장 밝을 때 눈 둘레 십자 빛.
4. 그 뒤 지금의 어둠 상태(주인공 칸만 보임, 기둥은 희미하게)로 이어진다. 등불 3개·근위병 소환 등 규칙은 그대로.
- 화면 흔들림은 넣지 않는다. 보스마다 전환 연출을 다르게 한다는 방침이다.

### 2-2. 망령 왕 2→3단계
- (결정, 바뀜) 쓰러질 때 머리 위에 뜨던 "왕관이 깨졌다!" 글자(`wraithking.phase3_status`)를 **띄우지 않는다**. 나머지(하얀 번쩍임, 넋 입자, 푸른 번쩍임, 왕관 깨짐, 천천히 쓰러짐)는 그대로.

### 2-3. 여제 단계 전환 (결정)
- 1→2, 2→3 전환 때 지금 연출(꽃잎 고리 사라짐, 순간이동)은 그대로 두고, **화면을 아주 살짝 흔든다**(1픽셀, 약 0.15초). 다른 여제 이펙트는 바꾸지 않는다.

### 2-4. 여제 서리창·화염창 조준선 (결정, 새 연출)
여제는 기술을 몰아쳐서 플레이어가 머리 위 숫자를 놓친다. 창이 **날아오기 1턴 전**(다음 여제 턴에 날아가는 상태)에만 아래 셋을 함께 보여 준다. 그 전 턴들은 지금처럼 숫자만.
1. **조준선**: 창에서 주인공 쪽으로 가는 가는 점선(1픽셀, 2픽셀 켜짐·2픽셀 꺼짐, 끝 쪽으로 흐르듯 움직임). 서리창 = 옅은 하늘색, 화염창 = 주황. 강화 마탄의 보라 굵은 궤적과 헷갈리지 않게 가늘게.
   - 실제로 창이 날아갈 길과 **같은 경로 계산**(`Ballistica`)을 쓴다. 주인공이 움직이면 그 턴에 다시 그린다.
   - 벽·기둥에 막히면 선이 그 앞에서 끊기고, 끊긴 자리에 같은 색의 작은 × 표시. "선이 나에게 닿으면 맞는다, 끊기면 안전하다"가 보이게.
2. **창 겨누기**: 머리 위 창이 주인공 쪽을 향해 돌아가고, 창끝이 한 번 반짝인다. 남은 턴 숫자는 여제 머리 위가 아니라 **창 옆**에 붙인다.
3. **발밑 표식**: 조준선이 주인공에게 닿을 때만, 주인공 칸 발밑에 창 색 작은 납작한 고리가 은은하게 깜빡인다(막혔을 때는 없음).
- 주인공이 투명(은신)이면 셋 다 보이지 않는다(창이 주인공을 인식하지 못하는 규칙과 같다).
- 서리창·화염창 **둘 다** 적용. 체력 바 밑 창 아이콘 + 숫자는 그대로 둔다.
